# Проект SQL + Ad-hoc: Анализ рынка недвижимости Санкт-Петербурга и Ленинградской области
## 🎯 **Цель проекта:**
Провести всесторонний анализ рынка недвижимости для определения наиболее перспективных сегментов и разработки стратегии выхода агентства на рынок Санкт-Петербурга и Ленинградской области. Проект направлен на помощь агентству недвижимости в выходе на новый рынок и разработке эффективной бизнес-стратегии.
